Merge PDF Files
Combine multiple PDF files into one document

Drop PDF files here or click to browse

You can select multiple files

How it works

  • Upload multiple PDF files
  • Drag and drop to reorder them
  • Click "Merge PDFs" to combine
  • Download your merged PDF
Restricted PDFs: If a PDF has copy/print restrictions, use "Unlock PDF" tool first, then merge the unlocked version.
All processing is done locally in your browser. Your files never leave your device.

Drop a password-protected PDF here

Select the PDF file you want to unlock

Leave empty to attempt automatic unlock, or enter password if you know it.

How it works

  • Upload a password-protected or restricted PDF
  • Enter password if you know it (optional)
  • Click "Unlock PDF" to remove protection
  • Download your unlocked PDF
Works without password for restriction-only PDFs. User password required for encrypted content. All processing happens locally.
