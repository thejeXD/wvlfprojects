## 📁 Project Structure

The repository maintains a clean, modular structure with separate folders for core assets and application logic:

```
WOLFGRADECALCULATOR/
├── apps/                       # Individual application HTML pages
│   ├── date-predictor.html
│   ├── followers-checker.html
│   ├── grade-calculator.html
│   ├── pdf-tools.html
│   └── randomizer-aguinaldo.html
├── assets/                     # Images, icons, and media files
├── css/                        # Stylesheets
│   ├── main.css
│   └── *.css                   # App-specific styles
├── js/                         # JavaScript files
│   ├── main.js                 # Core functions (Theme, Modal, Scroll)
│   └── *.js                    # App-specific scripts
├── apps-library.html           # Discovery page
├── contact.html                # Contact page
└── index.html                  # Main landing page
```

### 🚀 Getting Started

#### Installation

```bash
git clone https://github.com/thejeXD/WOLFPROJECTS.git
cd WOLFPROJECTS
open index.html
```

Or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
