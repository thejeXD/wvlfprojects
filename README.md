### ✨ Core Highlights

* **Multi-Subject Tracking** — Manage up to 15 subjects
* **Dynamic GWA Calculation** — Real-time grade computation
* **Grade Prediction Mode** — Auto-calculate required scores to pass
* **Customizable Formula & Weights** — Fully adaptable grading system
* **Light & Dark Themes** — Comfortable viewing anytime
* **Motivational System** — Random memes and fun messages for results

---

### 🚀 Getting Started

#### Installation

```bash
git clone https://github.com/thejeXD/WOLFPROJECTS.git
cd WOLFPROJECTS/grade-calculator
open index.html
```

Or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```

---

### 🧠 Usage Overview

1. Add subjects (up to 15)
2. Enter grades for each period
3. View GWA automatically in real-time
4. Adjust grading weights and thresholds
5. Export your report as a PDF

**Bonus:** “Grade Requirement Mode” auto-fills needed grades to pass missing periods.
