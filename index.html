About

Hi! I'm Wolf, a student and aspiring developer who builds tools to make life easier—especially student life! My passion is transforming ideas into simple solutions using web technologies (HTML, CSS, and JavaScript).

I'm still early in my coding journey, focusing on **practical, small projects** that solve real problems, like the Grade Calculator. When I'm not studying or building utility apps, I explore **game development** on the Roblox platform, where I learn complex logic and architect immersive worlds using Lua.

This site is a portfolio of my learning—a place for simple, effective tools and experiments. I believe in clean code and a straightforward user experience. Let's learn and build together!
